对于手办，先要了解一下手办的分类，下面按材质、生产方式、完成度和玩法，对常见手办进行分类。需要先说明：“手办”在中文市场中是一个比较宽泛的称呼，既包括PVC比例成品、景品，也经常包括树脂雕像、可动模型甚至人偶。不同圈子对“GK”的理解也不完全相同。

文中的价格主要参考中国大陆市场常见售价，以人民币计，只能作为大致区间。作品热度、尺寸、厂商、授权、限量数量、运输和二手行情都会造成很大差异。

# 先理解几个容易混淆的概念

# 1. PVC手办

通常指工厂批量生产、已经涂装并组装完成的塑料手办。虽然叫“PVC手办”，实际上往往是多种材料混用：

  • 人物皮肤、衣服、头发等部分多使用PVC
  • 武器、底座、关节或细长零件多使用ABS
  • 透明特效件可能使用透明PVC、ABS或亚克力
  • 少数零件可能加入金属桩、磁铁或布料

PVC手办是目前最主流、最适合普通收藏者的类型。

# 2. GK手办

GK是“Garage Kit”的缩写，直译为“车库套件”。

它最初指个人原型师或小型工作室制作的、未经组装和涂装的树脂模型套件。购买者需要自己完成：

  • 修件
  • 打磨
  • 补土
  • 假组
  • 钻孔打桩
  • 清洗
  • 上色
  • 组装

但在国内交易环境中，“GK”经常被泛指为树脂雕像，包括已经由工作室涂装完成的大型树脂成品。因此看到“GK”时，必须进一步确认它究竟是：

  • 白模套件
  • 官方授权树脂成品
  • 原创工作室树脂成品
  • 无授权同人雕像
  • 翻模白模
  • 翻模涂装成品

# 3. GK翻模

“翻模”是使用已有模型或成品重新制作模具，再复制出树脂零件。

广义上，正规生产过程本身也需要翻模，但收藏市场说的“GK翻模”，通常特指未经原作者或版权方许可，对原版套件、PVC手办或树脂雕像进行复制。

它往往具有以下特征：

  • 没有原作者或版权方授权
  • 价格明显低于原版
  • 细节可能逐代损失
  • 零件变形、气泡、缺肉、合模线较多
  • 需要投入大量修件工作
  • 版权和交易风险较高
  • 很难获得稳定的售后服务

所以“翻模”并不等于单纯的“便宜版GK”，它和正版原模、正版套件在来源、质量和收藏价值上都有明显差别。

这里只对手办分类做一个简单的描述，想了解更多的可以去看我接下来写的一篇文章。

第八个是Anigame 柴郡 绚烂夜梦，这个是临时起意买的，本来还在想要不要买这个，然后发现拿到货的人评论说是这个可以开盖的，有细节，那还说啥了，于是去闲鱼收了一个转单的，当时是收的比较低的价格，但是后面发现还有更低的价格，但是不重要了以及，

# EMONTOYS 贝尔法斯特

第九个是EMONTOYS 贝尔法斯特，这个是回去之后收的手办，虽然我看hopi都说这个做的不行，但是我收到手之后觉得其实还好，本身没啥质量问题，我看面雕什么的也还行，细节上也没啥问题，看他们在骂的点就是说还原的是动漫里的贝法的样子，但是我觉得其实还好，都挺好看的，而且我收的也算是比较便宜的。

# Alter 可畏 重装

第十个是Alter 可畏 重装，这个我其实也是馋了很久了，但是一直没买，到过年的时候突然发钱了，嘿嘿就拿下了，这个我看评论说是可畏里面质量很高的手办了，本身做工足够精细，而且面雕很不错，加上我收的这个是无损的拆摆，价格也是很不错的，

# Apex 花园 白雪之仪

第十一个是Apex 花园 白雪之仪，这个我在收之前就看到过，但是当时一直没打算买，后面看出货之后的评论都是夸这个的，唯一有点可惜的就是太大了，这个虽然是七分之一比例的手办，但是这个整体的大小比不少四分之一的都占的大，而且我看说这个质量和面雕什么的都很好，本来这个当时打算买的时候有一个好价的，但是当时犹豫了一下，结果直接被买走了，法克，拍大腿，后面才又找到一个既带特典又算是价格可以的收了，

# POKO 武藏

第十二个是POKO 武藏，这个是无意之间在淘宝看到的一个图片，当时觉得这个简直了，找了半天才找到这个叫什么，然后就打算收一对来着，也就是武藏和信浓一对，当时看价格都挺贵的，后面收藏的一个突然降了很多价，但是当时正准备去西安，还没找好住的地方，这也就导致没法收快递，所以又没买到，被别人买走了，但是过来之后，发现了一个人出武藏的，她也在西安，价格也可以，所以我就去自提了，去取的时候发现出这个的人竟然是个妹妹，感到大为吃惊，这种女雕也有女生在玩吗。。。打算什么时候再把信浓收了，

# TAITO 时崎狂三

第十三个是TAITO 时崎狂三，这个是个景品，但是这一系列的都做的挺好，而且这个很便宜，我就买了，这个的价格是40元。

# Mimeyoi 瑞鹤 飙速之鹤

第十四个是Mimeyoi 瑞鹤 飙速之鹤，这个是我在逛闲鱼的时候偶然间看到的，图片里没有具体的人物，但是我看名字认出来这个是瑞鹤的那一款手办，而且价格很好，就直接拿下了，嘿嘿，也算是捡漏了，我看这款的价格一般平均是在750左右，但是我收的是570元，纯纯好价。

以上就是我购买的全部手办了，当然还有不少是想买但是还没买的，以后再买新的手办我会在这下面更新的。

我还是先把想买的手办都列一下吧，给你们看看这些，嘿嘿。

# 想要的

# POKO 信浓

第一个就是POKO的信浓了，毫无疑问这个是和之前的POKO武藏凑成一对摆起来的。

# GSC 魔女之旅 伊蕾娜

第二个是GSC 魔女之旅 伊蕾娜，这个是才出的，这个是我见过最好的伊蕾娜了，我看那么多伊蕾娜手办，就这个最好看，等出货了一定要搞一个。

# APEX 洛天依 十二周年

第三个是APEX 洛天依 十二周年，这个看着效果也无敌好看，而且不用多说，洛天依我也很喜欢，所以到时候出货了也整一个。

# APEX 大凤 绮愿良宵

第四个是APEX 大凤 绮愿良宵，大凤的手办其实有很多，但是我觉得好看的就三个，一个是已经买了的那个大A的夏日皮肤手办化的，一个是那个大A的风纪委员皮肤手办化的，还有一个就是这个兔女郎皮肤手办化的了，这个是真的好看，到时候整一个。

# Reverse Studio 香奈美 花的私语

第五个是Reverse Studio 香奈美 花的私语，这个和星绘是一个工作室出的，做工和效果都挺好的，等出货了也整一个。

# WINGSinc 武藏

第六个是WINGSinc 武藏，这个是武藏的原皮，感觉效果很好啊，很大一个非常霸气，超级好看，但是这个厂天天延期，还是吃现吧，等真正出货了再整一个。

# Apex 天城 走水静莲

第七个是Apex 天城 走水静莲，这个其实看了很多遍了，效果很不错，没啥说的，就是很好看，而且也降了很多价了，等啥时候整一个，

# Apex 信浓 轰鸣的银轮

第八个是Apex 信浓 轰鸣的银轮，这个也是和之前欧根赛车皮一个系列的，这个系列的手办都很不错，而且会降不少价格下来，本来以为这个不太行呢，结果效果图出来之后发现其实还挺好看的，等到时候出货降价了搞一个。

# Mimeyoi 翔鹤 急速之鹤

第九个就是Mimeyoi 翔鹤 急速之鹤，这个同样是和之前的瑞鹤摆一起的，这个也是降价大王，从原价快2k一直降到现在七八百，不过还不赖，这个虽然是四分之一的比例，但是她的姿势是趴着的，这也就使得这个手办不是很难放，嘿嘿，现在在考虑要不要收一个那个的大礼包，里面有这个手办还有一个嘉然的手办，还有一堆乱七八糟的东西，感觉其实可以收一个。嘿嘿。

# Anigame 伊404

第十个是Anigame 伊404，这个我看效果图是真的好看啊，而且这个手办设计的很有创意是那种吊起来的，可以来回晃荡秋千，嘿嘿，到时候出货了一定要整一个。
